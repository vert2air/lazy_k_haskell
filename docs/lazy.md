# lazy

Lazy K インタプリタ

## コマンド形式

lazy [-d [<頻度_1>],[<頻度_2>]] [-v] [--max <最大byte数>] <ファイル名>

## 説明

<ファイル名> のファイルに格納されている Lazy K のソースコードを実行する。
入力は、標準入力から受け取る。
出力は、標準出力へ出力する。

* -d <頻度_1>,<頻度_2>

  debug用に進捗状態を示す為に、最外最左のbeta簡約を<頻度_1>回実施する度に"*"を、その先のbeta簡約を<頻度_2>回実施する度に"."を、標準エラー出力に表示する。頻度_1、頻度_2には数値を指定するが、下線を含めることが可能。下線は桁数の多い数字を見易くする為の使用を想定しており、オプションの解析時には無視される。

  例: `-d 100,1_000_000`

* -v

  debug用の出力ログを、標準エラー出力に出力する。

* --max <最大byte数>

  <最大byte数> byte を出力した後、インタプリタを終了する。無限に出力するプログラム等での使用を想定。

## 例

入力を 2byte 受取り、その合計を 1byte で出力する例。

```
$ echo -ne '\x30\x08' | cabal run lazy -- lazy/add_A_B.lazy | od -tx1
0000000 38
0000001
```

入力を必要としない Lazy K コードの実行。

```
$ cabal run -O2 lazy -- --max 6 lazy/prime_numbers.lazy
2 3 5
```

入力を必要としない Lazy K コードの実行。
進捗を示す*と.を表示しながら、6文字出力した時点で終了。

```
$ cabal run -O2 lazy -- -d 100,1000 --max 6 lazy/prime_numbers.lazy
...2. ..*....3. ..*........................5.*
```

進捗の*,.に加え、開始終了時刻、byte毎の出力時間などのdebug情報も出力。

```
$ cabal run -O2 lazy -- -d 100,1000 -v --max 6 lazy/prime_numbers.lazy
Start time : 0
...50(='2')
2.32(=' ')
 ..*....51(='3')
3.32(=' ')
 ..*........................53(='5')
5.*32(=' ')
 Time: 0.21875 sec
```
