# lazy

Lazy K インタプリタ

## コマンド形式

lazy [-d [<頻度_1>],[<頻度_2>]] [-v] [--max <最大byte数>] [-l] <ファイル名>

## 説明

<ファイル名> のファイルに格納されている Lazy K のソースコードを実行する。
Lazy Kへの入力は、標準入力から受け取る。
Lazy Kを実行して得られた出力は、標準出力へ出力する。
lazy の終了コードは、Lazy Kを実行して得られた出力で、最初に 255 を超えた値から 256 を引いた値。

* -d <頻度_1>,<頻度_2>

  debug用に進捗状態を示す為に、最外最左のbeta簡約を<頻度_1>回実施する度に"*"を、
  その先のbeta簡約を<頻度_2>回実施する度に"."を、標準エラー出力に表示する。
  頻度_1、頻度_2には数値を指定するが、下線を含めることが可能。
  下線は桁数の多い数字を見易くする為の使用を想定しており、オプションの解析時には無視される。

  例: `-d 100,1_000_000`

* -v

  debug用の出力ログを、標準エラー出力に出力する。

* --max <最大byte数>

  <最大byte数> byte を出力した後、インタプリタを終了する。無限に出力するプログラム等での使用を想定。

* -l

  Lazy K の中のコンビネータ関数を一度ラムダ式に置き換えてから実行する。
  v1.0 で採用していた方式。処理時間は長くなる。

## 例

入力を 2byte 受取り、その合計を 1byte で出力する例。

```
$ echo -ne '\x30\x08' | cabal run lazy -- lazy/add_A_B.lazy | od -tx1
0000000 38
0000001
```

入力を必要としない Lazy K コードの実行。

```
$ cabal run -O2 lazy -- --max 6 lazy/prime_numbers.lazy
2 3 5
```

入力を必要としない Lazy K コードの実行。
進捗を示す*と.を表示しながら、6文字出力した時点で終了。

```
$ cabal run -O2 lazy -- -d 10000,1000 --max 6 lazy/prime_numbers.lazy
2. .3. .*.....*5....
```

-l オプション使用時。

```
$ cabal run -O2 lazy -- -d 100,1000 --max 6 -l lazy/prime_numbers.lazy
...2. ..*....3. ..*........................5.*
```

-vオプションにより、進捗の*,.に加え、開始終了CPU時間、byte毎のCPU時間などのdebug情報も出力。
