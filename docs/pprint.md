# pprint

Lazy K と ラムダ式 を指定のスタイルや変数の名前付けで表示

## コマンド形式

pprint [-c|-u] [-i|-l|-m|-s] [-p <変数名>] [-s <抽象化記号>] {-e <式>|<ファイル名>}

## 説明

### CC スタイルと Unlambda スタイルの選択

<式>に、S, K, I, s, k, Unlambdaの i, のいずれかが含まれる場合に、
その部分をどう表示するかを指定する。

* -c または --CC (default)

  CC style で表示する。

* -u または --Unlambda

  Unlambda style で表示する。

### 変数の名前付けの指定

<式> に含まれる、ラムダ抽象で導入された変数は、内部的には de Bruijn Index で表現されている。
これらの変数にどのように名前を付与するかを指定する。

* -i または --policy-index

  名前を与えず、de Bruijn Index のまま表示する。
  Jot式等と区別するため、'_'<index> の形式で表示する。-p および --pool オプションは無視する。

* -l または --policy-level

  <式>中の変数がラムダ抽象の何階層目に当たるかに注目し、
  階層毎に名前を与える。階層毎にどの名前にするかは、変数名プールで指定する。
  階層の浅い方から順に、プールの先頭から割り当てていく。
  変数名プールより深い階層の変数は、de Bruijn Indexとして '_' 付きで表示する。

* -m または --policy-minimum (default)

  変数名プールの先頭から順に変数名を割り当てるが、
  再利用できる場合は可能な限り最小の個数の変数を使用するようにする。
  シャドウイングの発生を気にしない。
  変数名プールで足りない場合は、de Bruijn Indexとして '_' 付きで表示する。

* -s または --policy-single-use

  各ラムダ抽象に、変数名プールの先頭から順に、別々の名前を割り当てる。
  変数名プールを使い切った後は、de Bruijn Indexとして '_' 付きで表示する。

### 変数名プールの指定

変数名プールの変数名をどのように使用するかは、「変数の名前付けの指定」の項を参照。

個々の変数名は、英字一文字 (a から z および A から Z) から成る。
但し、I, K, S, i, k, s は、Lazy K の関数名と重複するので、変数名としては使用しない。
また、下線('_') および 半角空白(' ') を含めることができる。
この場合、変数名ではなく De Bruijn Index で '_'付きで表示する。

* -p または --pool

  変数名プールを指定する。Default は、'xyzabc...wXYZABC...W'。

### 抽象化記号の指定

'λ'を表示できない環境での使用を考慮して、抽象記号を指定可能にしておく。
尚、抽象記号は環境変数 LAMBDA_SIGN で指定することも可能。

* -s または --lambda-sign

  ラムダ抽象の記号を指定する。1文字で指定する。Defalut は 'λ'。

### <式> のコマンドラインでの直接指定

* -e または --expr=Expression

  ラムダ式を、ファイルの内容からではなく、コマンドライン上で直接指定する。
